# Active yaw control (AYC): model, error and response — 7846816A (E9x M3)

How the DSC decides that the car is yawing wrongly and what it does about it: the vehicle model and yaw target, the
yaw error and its thresholds, the brake and engine response, the DSC modes, the coupling into ABS, and the numeric
limits. Steering input and the vehicle-model rows are covered in `DSC_STEERING_AND_VEHICLE_MODEL_7846816A.md`. This
doc builds on it.

Read from the disassembly (`analysis/7846816A_main.lst`), not bench-tested. CPU addresses; file = CPU + 0x8000.
Tags: **[C]** read from code on this image; **[C-1M]** read on the 1M (7846411A) and carried over, because the M3 AYC
functions are opcode-identical (cycle 2 diff) and the AYC block is byte-identical apart from three per-variant
arrays; **[I]** inferred; **[open]** not traced. Yaw-rate unit is 1/20000 rad/s (349 counts = 1°/s), lateral
acceleration is mg internally and 0.01 g in s8 copies, speed is 0.01 km/h. Symbol tables: `7846816A_symbols.md` §
"AYC / yaw control & DSC mode", "Vehicle-model derived coefficients and yaw references", "Sensor conditioning, AYC
observer & distribution".

## 1. Overview

```
vehicle-model rows (coding variant 0x4031AA+1)
  └─ loaders 0x5DE44 / 0x5E424 (init) ──► coefficients 0x400AA4..0x400AF8
steering 0x40212E (road-wheel), vref, ay, μ
  ├─ closed-form reference  yawref_stage_main 0x90D10 ──► r_ref 0x4020EC
  └─ dynamic observer       yaw_observer 0x5EBC4 ──────► target B1A 0x400B1A
measured yaw 0x402100 (cluster F-CAN 0x0CD) ──► AYC copy B46 0x400B46

e = B46 − B1A                                   yaw_error 0x60CA0
entry |e| > B6C, hold while |e| > B70           ayc_threshold_stage 0x602DA / clamp 0x60682
M = P·(|e| − B70)·sign(e) + D·ė                 yaw_pd_moment 0x5F7BA (gains: ayc_gain_stage 0x60714)
M ──► one or two wheel pressures                ayc_moment_to_wheel_pressure 0x616A4 ──► arbiter ids 3 / 20
  └─► engine torque cap 0x400B30                ayc_torque_cap_B30 0x65494 ──► DME request (TX 0x0B6)
B1A also read directly by 14 ABS sites (§8)
```

AYC runs every 10 ms inside the DSC task [C-1M]. Everything is in fixed-point integer arithmetic.

## 2. Preconditions and inhibits

- **Sensors and frames [C].** AYC needs a valid steering angle (SZL, F-CAN 0x0C9), the yaw / lateral cluster
  (0x0CD / 0x0D1), and the DME torque frames (0x0A8 / 0x0A9 / 0x0AA). A missing SZL sets `sensor_reaction_word`
  0x402888 b0 | b2 | b3, which also invalidates lateral and yaw. A DME timeout sets group A 0xA0008. Both go
  through `fault_reaction_matrix` 0xB567E to 0x402880 b2–b5. b2 blocks and aborts an AYC intervention (0xB5CD0);
  b3–b5 are read in the AYC code (0x5FEE0, 0x6028E, 0x66E7A). 0x402882 b4 sets the DSC inhibit 0x400DF4 b6.
  (FACTS "Steering-sensor loss", "DSC driver mode".)
- **Driver mode [C].** DSC off (driver mode 0): `driver_mode_is_on` 0x8D060 is false, the yaw state select 0x68E5E
  picks state 2, and 0x69F6E sets the DSC inhibit 0x400DF4 b6. DSC on and MDM run AYC. Switching on → off or
  on → MDM is refused while an AYC intervention runs (0x400B0A b2 vs b7).
- **AYC active flags [C].** 0x400B0A b7:6 = AYC / torque intervention active (CAN status bit 2 is 0x400B0A & 0xC0);
  b2 = NOT b7, used by the mode-transition check. ABS reads 0x408DEA+6 b7 / b6 as "AYC active" (§8).

## 3. Vehicle model

### 3.1 Rows and loaders [C]

Twelve columns per row, one per coding variant `0x4031AA+1`. The loaders run at init and read only the coded
column. Full row list, the per-word coefficient formulas and their checks: `7846816A_symbols.md` § "Key
calibration addresses" and § "Vehicle-model derived coefficients".

| Row | Content | M3 variant 0 |
|---|---|---|
| l_f 0xD6F42, l_r 0xD6F5A | CG to front / rear axle, Q10 m (wheelbase = sum) | 1.380 / 1.380 m |
| m 0xD6F72 | mass, kg (driving mass) | 1787 |
| Jz 0xD6F8A | yaw inertia, kg·m² | 2999 |
| Cf 0xD6ECA, Cr 0xD6EE2 | axle cornering stiffness, units not decoded | 7527 / 10596 |
| t_f 0xD6FA2, t_r 0xD6FBA | tracks, Q10 m | 1.538 / 1.536 m |
| x 0xD6F2A | −(sensor distance behind the front axle), Q10 m [I] | −1.176 m |
| y 0xD6F12 | sensor lateral offset from the centreline, Q10 m [I] | 0.436 m |
| 0xD6EFA | divisor in the track terms; possibly CG height [I, low] | 532 |
| 0xD7002, 0xD6FD2 | 12 × 2 per-variant pairs, roles not traced | {50, 20}, {10000, 14000} |

Variants 0–4 and 5–9 are identical; 10 / 11 (GTS) differ. The only readers of these rows are the two loaders. The
steering-ratio curve (0x40EB4 / 0x40ECC) is in the steering doc §3.

### 3.2 Characteristic speed [C]

The model is a linear single-track (bicycle) model. Its steady-state yaw gain is

```
r / δ = v / (L · (1 + v²/v_ch²))        v_ch² = L²·Cf·Cr / (m·(Cr·l_r − Cf·l_f))
```

v_ch is not stored. It comes out of the loader as 0x400AE8 = L·675/1024 and 0x400AEA, with
v_ch² = 32·AEA·AE8 in (0.01 km/h)². Stock per variant: {0/5: 128.8, 1/6: 109.1, 2/7: 136.8, 3/8: 109.0, 4/9: 121.8,
10: 142.1, 11: 105.5} km/h.

In physical terms the understeer gradient is K = L·g / v_ch² (front minus rear slip angle per g). The M3 variant 0
model has K ≈ 1.2° per g. The per-kg stiffness ratio (Cr/W_r)/(Cf/W_f) is 1.41.

Consequences, from a replay of both loaders against the image [C]:

- **The model must understeer.** Cr·l_r − Cf·l_f is a divisor. If it is zero (neutral model, Cf/Cr = W_f/W_r) the
  loader divides by zero. If it is negative (oversteering model) it divides unsigned by a negative number, and the
  coefficients are garbage.
- **v_ch is capped at about 194 km/h.** Observer coefficient 0x400AD8 ≈ 0.871·v_ch² (km/h)² saturates there, and
  0x400AF8 ∝ v_ch² follows it. Stock is 14444 at 128.8 km/h.
- **Other numeric limits:** mass below ~586 kg wraps 0x400AB6, Cf above 18745 wraps 0x400AAE, and Cr above 25000
  wraps 0x400AB2. 0x400ADA (∝ L²·Cf/(l_r·m)) saturates above about 3.1 m wheelbase at M3-like per-kg stiffness.

### 3.3 Sensor position [C formula, I role]

The loader turns x and y into lever arms for `ay_axle_est_calc` 0x8FFE8. That function moves the measured lateral
acceleration to the CG, the front axle and the rear axle as a rigid body:

```
ay_P = ay_sensor + α·x_P + ω²·y_sensor
```

- **Longitudinal:** 0x400AEC / AF0 / AF2 hold the CG, front-axle and rear-axle positions relative to the sensor, in
  ≈ 0.19 m steps.
- **Lateral:** 0x400AEE = 10240000/(167·y) holds the offset. The ω² term (yaw/256)²/AEE in mg matches ω²·0.4355 m
  exactly, which identifies the role of the 446 row.
- **Outputs:** 0x402126 (CG), 0x402124 (front axle) and 0x402125 (rear axle), as s8 in 0.01 g. BCO reads the CG
  value; the ABS reads the front-axle value through `abs_ay_aux1_get`.

## 4. Yaw references

### 4.1 Closed-form reference [C]

`yawref_stage_main` 0x90D10:

```
r_ref = 4·(δ·v/16) / ((v²/16 + 2·AE8·AEA) / (8·AEA))  =  δ·v / (L·(1 + v²/v_ch²))
```

δ is the road-wheel angle 0x40212E, and v is vref 0x408DA8.

- **Clamp.** The result is clamped to ±(0x558C/(v/16))·256. r·v ≤ 21900·4096/(20000·360) m/s² = 12.46 m/s² =
  **1.27 g**. The yaw limit is also capped at 127·256 counts (93°/s) at low speed.
- **Outputs.** The result is r_ref 0x4020EC, which has low-passed copies 0x40215E (221/256), 0x4020EE (205/256) and
  0x402166 (241/256).
- **Readers of 0x4020EC.** The observer (for its first 12 cycles, §4.2), `chassis_state_flags_update` 0x91070, 0x90660
  and the ABS seed block in `sub_055420` (0x55420).

The same function also builds the redundant yaw rates the plausibility monitors compare:

| RAM | Estimate | Formula |
|---|---|---|
| 0x40215A | front-axle wheel-speed yaw | LP 221/256 of `wheel_yaw_k` 0x400AF4 · (speed difference) |
| 0x40215C | rear-axle wheel-speed yaw | same, rear pair |
| 0x402160 | yaw from lateral accel | ay(0x402AB6, 0.01 g)·88290·8/v above 10.8 km/h, clamped like r_ref |

0x400AF4 = round(56888/t_f), so the front track sets the wheel-speed yaw scale.

`yaw_steer_equiv_update` 0x9053C converts the wheel-speed yaws, measured yaw and yaw-from-ay into equivalent
road-wheel angles 0x40217A / 7C / 7E / 80 (δ = r·L·(1 + v²/v_ch²)/v) for the steering monitor 0xB97D4.

`steer_yaw_consistency_check` 0xBB888 forms the linear model yaw 0x402A60 = v·(δ − K·ay)/L, using 0x400AF6 ∝ L and
0x400AF8 ∝ v_ch². It counts 0x402ABD up while |0x402A60| exceeds |0x40215E| by more than 2°/s. What the counter
feeds is [open].

### 4.2 Dynamic observer → yaw target [C-1M, M3 variant arrays C]

`yaw_observer` 0x5EBC4, called from `ayc_obs_wrapper` 0x5EAC8. It is a discrete nonlinear single-track model with
states sideslip β 0x400C42 and yaw rate 0x400C44, using trapezoid integration over a 10 ms step. Per cycle:

- **Slip angles** α_f / α_r, from β, yaw rate, l_f / l_r and v.
- **Front slip-angle lag**, weighted by the per-variant curve 0xD704A (Q13) over 0xD70AA (speed). v0–9 are
  7229 / 6560 / 5200 / 3014; variants 10 / 11 differ.
- **Front tyre force in three regimes:** linear, knee, saturated. The knee comes from the per-variant arrays 0x415F8
  (1835), 0x41610 (90) and 0x41628 (11905; 17854 for variants 1 / 6), scaled by the friction estimate μ.
- **Linear rear force**, then the β̇ / ṙ equations of motion using the loader coefficients.
- **Friction clip** of about μ·g/v on the target yaw rate.

The output is the **target yaw rate B1A 0x400B1A**. For the first 12 cycles after a reset (counter 0x400C41) it is
seeded from r_ref 0x4020EC. Validated on the 1M with an integer replica (`agents/yawmodel/sim.py`): gain peaks near
v_ch and the step response is about 10 ms.

### 4.3 Friction estimate μ [C]

- **Storage.** μ is 0x400B8F, a u8 in percent. It is initialised to 100 (0x647A0), and forced to 100 by the wrapper
  while 0x400B4C ≠ 0.
- **Estimator.** `sub_064234` estimates it from the AYC lateral inputs 0x400B38 / 0x400B39, which are s8 in 0.01 g,
  plus further state not traced.
- **Clamp.** At 0x64526 μ is limited to **120 (1.20)**. Because the inputs are s8 in 0.01 g, the estimator can't see
  more than 1.27 g in any case.

So the target's friction capacity tops out at about 1.2 g, whatever the car can do (§9).

## 5. Yaw error and thresholds

### 5.1 Error [C]

`yaw_error` 0x60CA0: e = B46 − B1A, where B46 0x400B46 is the AYC copy of measured yaw from `ayc_input_gather`
0x647D4.

e is the raw signed difference (0x400B14 = e saturated to ±32767, 0x400B16 = |e|). With ISO 8855 signs (positive yaw =
left turn, confirmed by the owner 2026-10-26):

- **left turn:** e > 0 is oversteer (the car yaws more than the target), e < 0 understeer;
- **right turn:** the reverse, e < 0 is oversteer.

So "oversteer" below means e in the direction of the turn. Where the mode logic (§6.2) compares e with the turn
direction was not traced [open].

### 5.2 Entry, hold and persistence [C-1M, values C]

```
B6C (entry) = base · f(v, m) / 128, clamped to ceiling[m]          ayc_threshold_stage 0x602DA, clamp 0x60682
B70 (hold)  = B6C − hold_offset[m], clamped to hold_ceiling[m]
active when |e| > B6C (after a persistence count ≥ 79), stays active while |e| > B70
```

| Calibration | Address | Stock |
|---|---|---|
| entry base, set A / B | 0x413BA / 0x413BC | 1396 (4.0°/s) / 2792 (8.0°/s) |
| hold seeds | 0x413BE | 698 / 2094 |
| hold offset [m] | 0x4141E | 698 (2.0°/s) ×3 |
| entry ceiling [m] | 0x41424 | 10471 / 10471 / 8028 (30 / 30 / 23°/s) |
| hold ceiling [m] | 0x4142A | 9773 / 9773 / 7330 |
| speed factor, set A x / y [m][4] | 0x41478 / 0x41490 | x 0.01 km/h, y /128 |
| speed factor, set B x / y [m][4] | 0x414D8 / 0x414F0 | |

Entry threshold with set A, in °/s:

| m | 20 km/h | 50 | 80 | 120 | 160 | 200 |
|---|---|---|---|---|---|---|
| 0, 1 | 10.0 | 10.0 | 8.6 | 6.8 | 5.6 | 4.0 |
| 2 | 6.9 | 5.3 | 4.0 | 4.0 | 4.0 | 4.0 |

- **Shape.** The thresholds are round deg/s values and don't depend on the vehicle model. They are looser at low
  speed, where yaw rates are large and steering or model error turns into a large yaw error.
- **Symmetric entry.** Entry tests |e|, so oversteer and understeer use the same threshold.
- **[open]** The persistence unit and its reset, and what selects set A or set B.

## 6. Response

### 6.1 Yaw moment demand [C-1M, values C]

`yaw_pd_moment` 0x5F7BA (called from `ayc_moment_stage` 0x5F50E):

```
M = B76 · max(0, |e| − B70) · sign(e) / 16384  +  B78 · ė / 16384      → 0x400B1C
```

There is a dead-zone P term (nothing inside the hold band, and it starts from zero at the band edge) plus a D term
on the yaw-error rate, with a same-sign clip. `ayc_gain_stage` 0x60714 builds the gains:

| Calibration | Address | Stock |
|---|---|---|
| P / D gain base | 0x413AA | 47 / 47 (second set 36 / 36 at 0x413AE) |
| P-gain % against speed, x / y [m][4] | 0x41448 / 0x41460 | m0 / m1 30 / 60 / 70 / 100 %, m2 70 / 80 / 100 / 100 % |
| second % multiplier [m][4] | 0x41430 | m0 / m1 80 / 80 / 90 / 100 % |

The gains don't reference Jz or the brake hardware [I]. The same calibration gives a different loop gain on a car
with different inertia, track or brake torque per bar.

### 6.2 Wheel distribution and pressure [C]

`ayc_moment_to_wheel_pressure` 0x616A4. The mode is 0x400BB8 b7:6; the per-wheel demand is 0x400B0C[4], at about
0.1 bar per moment count, converted through the same COA p-V curves as ABS.

| Situation | Wheels braked | Calibration |
|---|---|---|
| oversteer (e in the turn direction, mode 2) | outer front only | |
| understeer (e against the turn direction, mode 3) | inside rear (same side) | `ayc_us_rear_share` 0x4155E = 256/256 rear; lower values move a share to the front |
| small yaw (mode 1) | front 192/256 + rear 64/256, rear doubled | `ayc_small_yaw_rear_gain` 0x413C4 = 64 |
| driver braking above the gate | different distribution branch [I] | `ayc_driver_press_gate_pct` 0x415E8 = 60 % |

`ayc_wheel_request_submit` 0x64A62 sends the demand to the pressure arbiter as id 3 (brake) and id 20 (front-outer
pre-fill):

- **Rate caps:** `ayc_req_rate_cap` 0x41552 = 300 / 500.
- **Pre-fill:** 0x411B4 = 500 (5 bar), held on the front outer wheel while armed.

### 6.3 Engine torque [C]

`engine_torque_request` 0x65078 and `ayc_torque_cap_B30` 0x65494: 0x400B30 = min(0x400D24, 0x400DB0). This is
min-merged into the DME torque request (`dme_torque_request_compose` 0xCC2C2) and sent on 0x0B6. The cap comes from a
per-mode curve over lateral acceleration:

| Calibration | Address | Stock |
|---|---|---|
| ceiling x [m][2] | 0x411FE | 50 / 80 |
| ceiling y [m][2] | 0x4120A | m0 150 / 400, m1 200 / 2000, m2 180 / 330 |
| scale % [m] | 0x41216 | 78 ×3 |

A higher ceiling allows more torque, so less engine intervention. The brake response works whether or not the DME
acts on the request.

## 7. DSC modes

`dsc_mode_select` 0xCF2E8 writes m to 0x4031B1 (= coding block + 7, shared with the traction-control mode index):

```
m = 0  if state 0x4030A4 ∈ {1, 4, 5} or tcs_mode 0x4030A2 ≠ 3 (i.e. not MDM)
m = 2  if MDM and coding byte 10 bit 5 (flag word A bit 7, NCS "USA M-Dynamic mode")
m = 1  otherwise (MDM)
```

DSC on runs m0 (DSC off also runs m0). Comparing yaw control with traction control (drive-slip set B,
`tcs_driveslip_curve` 0xC795E, 0xF625C + 0x22·m). That column is the *brake*-TCS base threshold; the entry limit adds
5 km/h and a low-speed extra, and the engine ASR allows only ≈ 1.5 km/h (m0) / 3–5 km/h (MDM). See
`TCS_7846816A.md` §4.1, §5.1:

| m | Allowed drive slip, 15 / 25 / 50 / 80 km/h | Yaw entry, low speed | P-gain, low speed | Torque ceiling at 0.8 g |
|---|---|---|---|---|
| 0, DSC on | 2.7 / 1.0 / 2.3 / 3.8 km/h | 10°/s | 30 % | 400 |
| 1, MDM | 8.7 / 8.1 / 6.5 / 6.8 | 10°/s | 30 % | 2000 |
| 2, US MDM | 7.7 / 7.1 / 5.5 / 5.8 | 5–7°/s | 70 % | 330 |

All modes converge above about 100–160 km/h.

How the modes divide the work [I]:

- **m0:** tight traction control prevents power oversteer, so the yaw controller can sit back at low speed.
- **m1:** loosens traction control and nearly lifts the AYC torque cap.
- **m2:** keeps most of m1's traction freedom but tightens the yaw backstop where traction control no longer
  prevents slides.

The feature enable 0xD6DA4 = 1 / 0 / 0 (m0 only) gates something not yet identified.

## 8. Coupling into ABS [C]

ABS reads the yaw target directly. These sites are gated on yaw valid (0x408E6D b4), not on steering or AYC. So with
a working SZL, parts of ABS cornering logic follow the vehicle model even when AYC never intervenes. Detail in
`agents/abs_full/09_chassis_sensor_use.md` §7.6. e = measured yaw 0x408ECC − B1A.

| Site | Use |
|---|---|
| event classifier `sub_04D270` | yaw-deviation flag (±1400 / ±700 bands against filtered error 0x408ED8); yaw-limited dump flag; rear cornering latch snapshot 0x408EA2 |
| `abs_corner_peak_track` 0x5A4E4 | filtered error 0x408ED8 += (e − 0x408ED8)/35 |
| `abs_dump_forced_target` 0x57024 | e > 1°/s in the direction of yaw → forced-dump amount halved |
| pre-control 0x50894 | per rear: e growing past the latched 0x408EA2 |
| `abs_side_select` 0x5AEEE | e against ±3°/s, 2°/s + context, cal 0x40A3E, curve 0x40A66(vref) |
| `abs_yaw_deviation_monitor` 0x4A254 | runs every frame; snapshot branch only with AYC active; oversteer state 0x408DF1 b6 |
| `sub_055420` | seeds 0x409194.. with r_ref 0x4020EC (no reader found) |

Most of these thresholds are code literals of 1–3°/s, far tighter than the AYC entry thresholds. A model error that
never reaches AYC still shifts ABS cornering behaviour.

## 9. Numeric limits

| Limit | Where | Effect |
|---|---|---|
| Lateral g ±1.27 g | s8 0.01 g copies: 0x402AB6 (`abs_ay_get`), 0x402124–126, AYC inputs 0x400B38 / 39 | ABS lateral g, BCO and the μ estimator saturate at 1.27 g. The internal mg signals 0x4020DA / 0x40212C do not |
| r_ref and yaw-from-ay r·v ≤ 1.27 g | 0x90D2A | closed-form reference and 0x402160 stop at 1.27 g |
| μ ≤ 1.20 | 0x64526 | observer target capped at about 1.2 g of lateral acceleration |
| v_ch < ~194 km/h | 0x400AD8 saturation | a near-neutral model can't be represented |
| road-wheel angle < 50° | `steer_ratio_convert` s16 without saturation | the steering curve must keep SW/ratio < 50° |

**Above about 1.2 g of lateral acceleration [I].** Measured yaw keeps rising but the target doesn't, so e grows in the turn direction by
about (1 − 1.2/a_y)·r. That is an oversteer reading of roughly 607/v[km/h] °/s at 1.5 g. AYC entry compares it with
5–10°/s (§5.2), so tight corners at low speed can trigger outer-front braking in a steady corner. The ABS sites react
at 1–3°/s at any speed.

The plausibility monitors also compare quantities that are clamped at 1.27 g (yaw-from-ay, r_ref) with ones that are
not (measured yaw, wheel-speed yaw). These are 0xBA2B4–0xBE492, 0xD05CE and 0xBB888. Whether any of them sets a fault
at sustained high g is [open].

## 10. Parameters by effect

| To change | Parameter | Notes |
